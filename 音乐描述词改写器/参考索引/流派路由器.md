# 流派路由器（Genre Router）

将本文件作为第一层披露入口。把音乐简报（Music Brief）路由到一个主风格族；仅在有用时再路由一个次风格族。然后只阅读这些风格族的索引。

## 路由契约

1. 使用下文的别名表，将显式的流派名与文化市场用语规范化。
2. 主风格族依据用户的主要流派选择，而不是依据泛化的情绪形容词。
3. 只有显式融合或明确请求对比性色彩时，才追加一个次风格族。
4. 普通请求阅读的风格族索引不超过两个。
5. 在这些索引内，优先选择已经同时结合两种所需风格的卡片，再考虑混合不同的参考。
6. 除非输入提供了更强的流派、律动或配器证据，否则将 `ballad（抒情）`、`emotional（动情）`、`epic（史诗）`、`modern（现代）`、`dark（黑暗）`、`cinematic（影视感）` 视为修饰词。

## 常见别名

| 用户用语 | 规范化为 |
|---|---|
| 华语流行、国语流行 | Mandopop / C-pop |
| 粤语流行 | Cantopop |
| 国风流行 | East Asian pop，可选 roots/traditional |
| 氛围 R&B、另类节奏布鲁斯 | Alternative R&B |
| 复古电子 | 根据 synthwave/retrowave 还是 disco/house 线索分别判定 |
| 朋克流行 | Pop-punk |
| 后摇感 | 除非用户明确要求 post-rock，否则按 Alternative rock |
| 电影感 | 修饰词；只有配乐主导的写作才把 cinematic 当主族 |
| 史诗感 | 修饰词；只有存在管弦、预告或合唱证据时才选影视管弦族 |
| 燃、炸、强烈 | 能量线索，本身绝不构成流派证据 |

路由前先规范化拼写变体，如 `Hip Hop`/`Hip-Hop`、`Dance Pop`/`Dance-Pop`、`Synth Pop`/`Synth-Pop`、`R&B`/`R'n'B`。

## 融合规则

- `X with Y influences` 解释为：主 `X`，次 `Y`。
- 有序形式 `X / Y` 同样处理，除非用户明确赋予两者同等权重。
- 最多阅读两个风格族索引。第三种风格作为索引内的排序线索保留，不要打开第三个索引。
- 优先选择主索引中已经同时表达两种风格的混合卡片。
- 次参考只取其被请求的维度：配器、律动、人声处理、文化色彩、编曲或制作。
- 绝不允许次参考覆盖显式的流派、速度、人声、乐器或排除项约束。

示例：

- `Mandopop with trap R&B production`（华语流行 + trap R&B 制作）→ 主 `东亚现代流行`，依据演唱还是节拍语言占主导，次选 `现代R&B与新灵魂乐` 或 `嘻哈与说唱`。
- `Metalcore with Chinese traditional instruments`（金属核 + 中国传统乐器）→ 主 `金属与重型摇滚`，次 `根源、传统与世界民谣`。
- `Cinematic folk ballad`（影视感民谣抒情）→ 是歌曲时主 `当代民谣与原声`；是配乐时主 `影视管弦与史诗`。
- `Lo-fi female R&B` → 主 `现代R&B与新灵魂乐`；只有 Lo-fi 节拍是核心时才次选 `嘻哈与说唱`。

## 兜底路由

当用户没有给出流派时：

1. 使用律动证据，如摇摆（swing）、trap、四踩底鼓（four-on-the-floor）、碎拍（breakbeat）或原声扫弦。
2. 然后使用核心配器与人声演唱方式。
3. 然后使用文化或市场背景。
4. 如果只剩情绪或意象，阅读 [索引-通用流行与抒情.md](索引-通用流行与抒情.md) 并保持结果保守。

当存在更强的音乐证据时，不要只凭情绪路由。
